## 4. 視覚証跡（本番 origin、実ブラウザ）

Chromium（Playwright 1.63.0、`LD_LIBRARY_PATH` にローカル展開した
`libnspr4` / `libnss3` / `libasound2` を指定）で撮影。
`broken` は `img.complete && naturalWidth === 0` の枚数。

| ファイル | viewport | `<img>` | broken |
| --- | --- | --- | --- |
| `live-0.8.2/portfolio-list-1440.webp` | 1440×900 | 28 | 0 |
| `live-0.8.2/portfolio-list-390.webp` | 390×844 | 28 | 0 |
| `live-0.8.2/portfolio-m5-clock-1440.webp` | 1440×900 | 1 | 0 |
| `live-0.8.2/portfolio-m5-clock-390.webp` | 390×844 | 1 | 0 |
| `live-0.8.2/tools-text-counter-1440.webp` | 1440×900 | 0（Tool 内に img なし） | 0 |
| `live-0.8.2/tools-text-counter-390.webp` | 390×844 | 0 | 0 |

確認できたこと:

- `/portfolio` は 1440 で 3 列・390 で 1 列のカードグリッド。
- `/portfolio/m5-clock` は CMS のタイトル・本文・Period・facet と、R2 から
  配信された実画像を表示。
- `/tools/text-counter` はサイト chrome なしで viewport 全面。
  Tool 自体の style 未適用は #910 の既知の Tool 側課題で、本リリースで
  新たに悪化したものではない（2026-11-04 capture も同程度）。
