## 2. 本番 smoke（GitHub Readme Stats — 本リリースの目的）

個人専用ルート（パラメータなし）と旧 URL（パラメータ付き、後方互換）の
両方を実測:

| endpoint | status | viewBox | Cache-Control |
| --- | --- | --- | --- |
| `api` | 200 | 450×195 | `public, max-age=86400, s-maxage=86400, stale-while-revalidate=86400` |
| `api?username=rebuildup`（旧形式） | 200 | 450×195 | 同上 |
| `api/top-langs/` | 200 | 300×165 | 同上 |
| `api/streak` | 200 | 495×195 | `public, max-age=3600, …, stale-while-revalidate=86400` |
| `api/pin/?repo=my-web-2026` | 200 | 400×120 | `public, max-age=864000, …` |
| `api/pin/?repo=my-web-2025` | 200 | 400×120 | 同上 |
| `api/pin/?repo=Ae_MultiSlicer` | 200 | 400×120 | 同上 |

確認ポイント:

- **パラメータなし URL が 200** — 個人専用固定が本番で有効
- **`cache-control: public` + positive lifetime** — `sharedCacheIsolation`
  の shared-cache opt-in が効き、camo/CDN がカードを保持できる
  （v0.11.1 までは `private, no-store` で「画像が見つからない」の一因）
- **旧 URL も 200** — `rebuildup/rebuildup` README の param 付き URL は
  deploy 前でも deploy 後でも動く（パラメータは無視される）
- 描画寸法は v0.11.1 で検証済みの値と同一（MiniMax 6/6 PASS の artifact と同じ renderer）

## 3. 永続 SWR ストアの確認

`svg-store.ts` は Workers Cache API（per-colo）に描画済み SVG を保持する。
単発の curl では「2 回目が速い」ことを確認する程度で、stale 保証の直接検証は
unit test（`router.test.ts` の SWR describe、stale 即時返却・背景更新・
upstream 失敗時も 200 stale）に委ねる。本番での強制障害試験は行わない。
