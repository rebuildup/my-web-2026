# Platform: Cloudflare

Cloudflare-specific types and helpers. Capability code should not
import from here directly; bindings are passed in by the Worker entry
through function arguments or Hono's `c.env`.

The 0.1.0 Foundation release does not need anything beyond the
ambient `Env` type (generated by `pnpm run cf-typegen`). Helpers
land here as they are introduced in later releases.
