## 5. 障害時配信継続性（LKG）

- 実績: v0.15.0 期間中、stats push が 413 で失敗していた間も
  avatar 抜き snapshot（3.6KB）で全 surface が 200 配信を継続
  — push 失敗は既存行を上書きしないため LKG が成立
- snapshot 不在/不正時は honest `—` variant（ゼロ表示しない）—
  `stats-source.ts` の `null` 伝播を統合テストで固定済み
- 部分失敗: `sources.{graphql,streak,search}` が独立に `ok`/`failed` を
  記録し、失敗 source の指標は `null`（嘘の 0 にしない）。
  `sources.avatar` は `ok`/`unconfigured` を記録する（avatar 取得の
  失敗は `unconfigured` であり `failed` にはならない）
