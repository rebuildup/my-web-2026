### 3.1 この計測器自身が最初に出した誤検知（記録）

最初の実装は 8 surface を欠陥と判定した。すべて**計測器側の誤り**で、
Tool の欠陥ではなかった。

| 誤検知 | 実体 |
| --- | --- |
| business-mail-block / pomodoro の `overflow=1` | `position: absolute; width: 1px; height: 1px; left: -1px; overflow: hidden` の **screen-reader-only 要素**（`.sr-only` 慣用句）。`left = -1` を「左にはみ出し」と数えていた |
| text-counter / ae-expression の `rules=0` | 両 Tool は **inline style prop のみ**でスタイリングしており、stylesheet を持たないのが正しい（監査 §5 の表に既記載） |

修正は「期待値を緩めた」のではなく、**監査が既に確定していた事実を計測器に教えた**:

- 1.5px 以下の箱が `absolute` / `fixed` で clip されている場合は視覚的に隠れている
- 祖先に `overflow-x` の clipping か `opacity < 1` があれば、その要素は見えていない
  （pomodoro の dock label は親が `opacity: 0`、子の computed opacity は 1 なので、
  自要素だけを見る判定では拾えない — 監査 §6.2 と同じ理由）
- inline-style のみの 2 Tool は `INLINE_STYLED` として明示（出典つき）

これは #910 の §6.3（`documentElement.scrollWidth` では `position: fixed` の
shell の溢れを見られない）と同じ種類の失敗である。**「計測器が緑」と
「描画が正しい」は別**なので、判定を変えた根拠をここに残す。
